# Mindscape | Zeka & Odak Egzersizleri

Mindscape, uzamsal hafıza, görsel dikkat ve mantıksal planlama becerilerini geliştirmek amacıyla tasarlanmış web tabanlı bir bilişsel egzersiz platformudur.

---

## İçerikteki Oyunlar

### 1. Skyrise (Hafıza & Uzam)
* **Mantık:** Ekranda 1 saniyeliğine beliren sayıları ve konumlarını aklınızda tutun.
* **Amaç:** Sayılar kapandıktan sonra küçükten büyüğe doğru kutulara dokunarak kuleyi yükseltin!

### 2. Hızlı Eşleştirme (Dikkat & Odak)
* **Mantık:** Ekrana sırayla semboller gelir.
* **Amaç:** Gelen sembolün bir önceki sembolle aynı olup olmadığını hızlıca doğru kararlaştırın.

### 3. Şehir Yolu (Mantık & Planlama)
* **Mantık:** $5 \times 5$ boyutundaki şehir haritasında engelleri göz önünde bulundurun.
* **Amaç:** Yeşil başlangıç noktasından Kırmızı bitiş noktasına kesintisiz bir yol çizin.

---

##  Kullanılan Teknolojiler

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Ses Efektleri:** Web Audio API (Dış ses dosyası gerektirmeyen sentezlenmiş sesler)
* **Veri Depolama:** `localStorage` (Skorlar ve istatistikler tarayıcıda saklanır)

---

## Çalıştırma

Dosyaları bilgisayarınıza indirdikten sonra `index.html` dosyasını bir web tarayıcısında açabilir veya VS Code **Live Server** eklentisi ile çalıştırabilirsiniz.
